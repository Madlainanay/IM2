# Spin & Sip

## Projektübersicht

Spin & Sip ist eine Website, mit der man neue Cocktails entdecken kann. Mit einem Klick auf den Button „Spin for a Cocktail“ wird ein zufälliger Cocktail angezeigt. Dazu werden Informationen wie Bild, Zutaten und die Zubereitung dargestellt.

Das Projekt wurde im Modul _Interaktive Medien_ erstellt. Ziel war es, eine moderne und benutzerfreundliche Website zu entwickeln, die Daten aus einer öffentlichen API lädt und anzeigt.

## Ziel des Projekts

Das Ziel war die Entwicklung einer interaktiven Website, die Cocktailrezepte automatisch aus einer API abruft und übersichtlich darstellt. Dabei wurde besonders auf ein ansprechendes Design und eine einfache Bedienung geachtet.

## Verwendete API

Für die Cocktaildaten wurde die öffentliche API _TheCocktailDB_ verwendet.

_API-Link:_
https://www.thecocktaildb.com/api/json/v1/1/random.php

_Beschreibung:_
Die API liefert bei jedem Aufruf einen zufälligen Cocktail. Die Website zeigt die erhaltenen Daten direkt an.

Folgende Informationen werden von der API bereitgestellt:

•⁠ ⁠Name des Cocktails
•⁠ ⁠Bild des Cocktails
•⁠ ⁠Zutaten
•⁠ ⁠Mengenangaben
•⁠ ⁠Zubereitungsanleitung
•⁠ ⁠Glasart
•⁠ ⁠Kategorie

## Funktionen

### Zufälligen Cocktail anzeigen

Mit dem Button „Spin for a Cocktail“ wird ein neuer zufälliger Cocktail geladen.

### Cocktailinformationen anzeigen

Zu jedem Cocktail werden verschiedene Informationen angezeigt:

•⁠ ⁠Name
•⁠ ⁠Bild
•⁠ ⁠Zutaten
•⁠ ⁠Zubereitung
•⁠ ⁠Glasart
•⁠ ⁠Kategorie

### Favoriten speichern

Interessante Cocktails können als Favoriten gespeichert werden, damit sie später wieder aufgerufen werden können.

### Benutzerfreundliches Design

Die Website wurde übersichtlich gestaltet und ist einfach zu bedienen.
